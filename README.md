# VANDALZ — прототип №1

Кооперативная игра от первого лица: игроки-дудлы рисуют себе путь граффити из баллончика.
Это первый прототип: без графики и сети, только механика «нарисуй мост и перейди пропасть».

## Как запустить

1. Установи **Unity 6** (подойдёт и 2022.3 LTS) через Unity Hub.
2. Склонируй этот репозиторий.
3. В Unity Hub: **Add → Add project from disk** и выбери папку репозитория.
   Unity сама создаст недостающие папки `ProjectSettings`, `Packages`, `Library` — это нормально.
   (Другой вариант: создай пустой 3D-проект и скопируй в его `Assets` папку `Assets/VANDALZ`.)
4. В верхнем меню редактора: **VANDALZ → Создать сцену прототипа**.
   Появится сцена `Assets/VANDALZ/Scenes/Prototype.unity` — она пустая, это нормально:
   уровень собирается кодом в момент запуска.
5. Нажми **Play**, кликни в окно Game, чтобы захватить мышь.

Если меню VANDALZ не появилось — посмотри окно **Console**: там будет ошибка компиляции.
Запасной вариант без меню: в любой сцене **GameObject → Create Empty**, в инспекторе
**Add Component → SubwayLevelBuilder**, Play.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Shift | бег |
| Пробел | прыжок (к краю уступа — подтянешься) |
| ЛКМ (зажать) | рисовать текущим баллоном |
| E | подобрать баллон / пополнить краску в тайнике |
| G | выбросить текущий баллон |
| 1–4 / колёсико | сменить баллон |
| F | встряхнуть баллон — давление снова полное |
| Esc | пауза (клик — продолжить) |
| R | рестарт уровня |

## Уровень «Станция «Заброшенная»»

1. **Старт.** Тайник с краской (E), голубой баллон на скамейке, спот для тега «СТАРТ».
   У края пропасти лежит **воздушный баллон**.
2. **Пропасть над путями (8 м).** Мост воздушным баллоном — или полки на стенах обычным.
   Над путями — спот «НАД ПУТЯМИ».
3. **Средняя платформа.** Тут бродит **Закрасчик**: замечает краску рядом, закатывает её
   валиком и толкает игрока. Краска выше ~1.7 м от пола ему недоступна.
4. **Стена 3 м.** Нарисуй на ней полки обычным баллоном и залезь (у ящика справа удобнее).
5. **Верхний ярус.** Спот «ВЕРХ» и выход через турникеты.

Цель — выбраться. Бонус — закрасить все 3 спота (рамка засчитывается при 70% краски).
Упал — вернёшься к последнему чекпоинту, краска и баллоны остаются.

## Механики

- **Давление.** Долгое распыление «сажает» баллон: мазок тоньше, под конец краска «плюётся»
  с разрывами. Отпустил ЛКМ — давление восстанавливается; **F** — встряхнуть, сразу полное.
  Кольцо точек вокруг прицела — уровень давления.
- **Подтягивание.** Идёшь/прыгаешь вперёд к краю полки, ящика или нарисованного уступа высотой
  до ~1.75 м — персонаж сам подтягивается наверх.
- **Закрасчик:** бродит, оставляя липкий серый след (по нему идёшь медленнее); слышит баллон
  и идёт проверить; замечает краску и закатывает её; толкает игрока; сквозь него не пройти.
  **Пшикни ему в глаза** (любым баллоном) — ослепнет на ~4.5 с.
- **Теги.** Закрашенный спот даёт +40% краски во всех баллонах.

## Баллоны

- **Обычный** — рисует только по поверхностям: на полу и потолке плоское граффити,
  на стене объёмное (на нём можно стоять: линия — полка, диагональ — пандус).
- **Воздушный** (белый, светится) — рисует только в пустоте: мост на уровне ног,
  продолжение моста.
- У каждого баллона свой запас краски (обычный — 10 с, воздушный — 8 с), пополняется в тайниках.

## Стиль

Мультяшный «комиксный» вид, как на концепте: чёрные контуры, ступенчатый свет,
светящаяся неоновая краска с подтёками, грязное тёплое метро.

- `Resources/VandalzToon.shader` — шейдер всех объектов: cel-освещение + чёрный контур.
  Если он не собрался, игра откатывается на обычные материалы (проще, но не розовая).
- `Resources/VandalzPost.shader` + `VandalzPost` (на камере) — свечение (bloom),
  цветокоррекция, виньетка, зерно. Работает во встроенном конвейере (Built-in).

## Как устроено

Всё — графика, звук, уровень, интерфейс — генерируется кодом (`Assets/VANDALZ/Scripts`):

- **Уровень и атмосфера:** `SubwayLevelBuilder` (геометрия, свет, туман, расстановка),
  `EnvTextures` (кафель, бетон, тактильная плитка, ржавчина, дерево, афиши),
  `FlickerLight` (мерцающие лампы), `DustMotes` (пыль), `WorldText` (надписи в мире).
- **Игрок:** `FirstPersonController` (разгон, прыжок, шаги, толчки),
  `CameraRig` (покачивание, приземление, тряска, FOV при беге).
- **Краска:** `PaintSpray` (рисование), `PaintStroke` (мазок-меш, стирание), `PaintSpot`
  (твёрдые куски, застывание), `DripRunner` (подтёки), `PaintTextures`.
- **Баллоны:** `SprayCan`, `CanPickup`, `CanInventory`, `PaintStash` (тайник),
  `SprayEffects` (рука с баллоном и её анимации, частицы, звук, подсказка).
- **Игра:** `GameFlow` (заставка, пауза, чекпоинты, финиш), `VandalzHUD` (интерфейс),
  `TagSpot` (споты для тегов), `PaintEater` (Закрасчик).
- **Звук:** `ProcAudio` — все звуки синтезируются кодом.
- `VandalzInput` — ввод; работает и со старым Input Manager, и с новым Input System.
