# VANDALZ — прототип №1

Кооперативная игра от первого лица: игроки-дудлы рисуют себе путь граффити из баллончика.
Это первый прототип: без графики и сети, только механика «нарисуй мост и перейди пропасть».

## Как запустить

1. Установи **Unity 6** (подойдёт и 2022.3 LTS) через Unity Hub.
2. Склонируй этот репозиторий.
3. В Unity Hub: **Add → Add project from disk** и выбери папку репозитория.
   Unity сама создаст недостающие папки `ProjectSettings`, `Packages`, `Library` — это нормально.
   (Другой вариант: создай пустой 3D-проект и скопируй в его `Assets` папку `Assets/VANDALZ`.)
4. В верхнем меню редактора: **VANDALZ → Создать сцену прототипа**.
   Появится сцена `Assets/VANDALZ/Scenes/Prototype.unity` — она пустая, это нормально:
   уровень собирается кодом в момент запуска.
5. Нажми **Play**, кликни в окно Game, чтобы захватить мышь.

Если меню VANDALZ не появилось — посмотри окно **Console**: там будет ошибка компиляции.
Запасной вариант без меню: в любой сцене **GameObject → Create Empty**, в инспекторе
**Add Component → SubwayLevelBuilder**, Play.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | ходить |
| Shift | бег |
| Пробел | прыжок |
| ЛКМ (зажать) | баллончик |
| Esc / клик | отпустить / захватить курсор |
| R | рестарт: стереть краску, заполнить баллончик |

## Как устроено

Все скрипты — в `Assets/VANDALZ/Scripts`:

- `SubwayLevelBuilder` — собирает уровень из кубов: коридор метро, стартовая платформа (10 м),
  пропасть 7 м, дальняя платформа (10 м) с зелёным финишем; создаёт игрока и правила.
  Размеры можно менять в инспекторе на объекте LevelBuilder.
- `FirstPersonController` — ходьба, мышь, прыжок, гравитация на `CharacterController`.
  Есть «время койота» и буфер прыжка — прыгать с маленьких пятен легче.
- `PaintSpray` — баллончик. Пока зажата ЛКМ, рисует мазок. Твёрдое — само граффити,
  отдельных уступов нет: что нарисовал, то и получил.
  - пол / потолок ближе 7 м → плоское граффити;
  - стена → **объёмное граффити**, выступает из стены на 30 см: горизонтальная линия — полка,
    диагональ — пандус, зигзаг — ступеньки;
  - пусто → **мост**: полоса толщиной 10 см в воздухе в 3.5 м перед камерой (ширина 0.7 м);
  - верх моста → мост продолжается вперёд по взгляду.

  Краска лежит на отдельном слое (№ 8, можно назвать его «Paint» в Tags & Layers — необязательно).
  Луч для поверхностей проходит сквозь краску, поэтому она не нарастает сама на себя.
  Ширина граффити зависит от дистанции: 0.2 м вблизи, 0.6 м на 7 м; широкий мазок тратит
  больше краски. Каждое нажатие ЛКМ — новый цвет.
- `PaintStroke` — один мазок. На полу — плоская лента с текстурой баллончика и ореолом.
  На стене и в воздухе — объёмный «валик» густой краски: округлое сечение, скруглённые концы
  (одиночный «пшик» — капля), лёгкое свечение; мокрая краска глянцевая, высохшая — матовая.
- `PaintSpot` — невидимый коллайдер под твёрдым мазком. Свежая краска **мокрая**:
  светлее и проседает под игроком (до 0.7 м). Через 2.5 с застывает.
  По этому компоненту позже Закрасчик будет находить краску.
- `DripRunner` — **подтёк**: если подержать баллончик на одном месте стены 0.7 с, краска стекает
  вниз тонкой струйкой, а внизу остаётся капля, на которую можно встать.
- `PaintTextures` — текстуры краски, кляксы и частиц, сгенерированные кодом.
- `SprayEffects` — «ощущение» баллончика, на логику не влияет:
  - подсказка: полупрозрачная клякса цвета следующего мазка там, куда ляжет краска,
    и надпись под прицелом («стена — объёмное граффити», «воздух — мост», «продлить мост»…);
  - баллончик в руке, который наклоняется и дрожит при распылении;
  - струя краски к прицелу и облачка;
  - шипение (звук генерируется кодом), «кашель», когда краски меньше 20%,
    щелчок при нажатии на пустой баллончик;
  - лёгкая тряска камеры.
- `VandalzGame` — респаун при падении (краска остаётся), финиш, полоска краски и подсказки.
- `VandalzInput` — ввод; работает и со старым Input Manager, и с новым Input System.

Все числа (дальность луча, размер пятен, скорость, высота прыжка) — публичные поля:
во время Play выбери объект **Player** в Hierarchy и крути их в Inspector.
Изменения в Play-режиме не сохраняются — понравившиеся значения перенеси в код.
